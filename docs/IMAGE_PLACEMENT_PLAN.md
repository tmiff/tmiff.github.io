# ページ別画像配置方針

## 基本方針

- 写真は情報を補足する場所だけに使い、全セクションへ装飾目的で追加しない。
- 架空の観客、上映実績、審査員、受賞者、会場実績を事実写真のように掲載しない。
- 情報ページは原則として主画像1枚までとし、応募・規約・法務・確認画面は可読性を優先する。
- 画像ファイルと表示位置を分離し、`src/config/image-slots.json` で差し替えと焦点調整を行う。

## ページ別の想定

| ページ | 写真 | 役割 | 配置 |
| --- | --- | --- | --- |
| Home | 3枚 | 映画祭の第一印象、上映環境、オフライン形式の補足 | Hero全面、選考と賞の間の横長帯、In Person説明内 |
| About | 1枚 | 映画祭の文化的な雰囲気を示す | ページHero |
| Submit | なし | 応募条件とCTAの理解を優先 | 写真を置かない |
| Rules | なし | 規約の可読性を優先 | 写真を置かない |
| Selection Process | 1枚 | 作品確認を想起させる | ページHero |
| Awards | 1枚 | 賞の格式を示す | ページHero |
| Winners | 応募者提供スチル | 受賞作品そのものを示す | 許諾済み作品のみ月別カードへ掲載 |
| FAQ | なし | 検索と読みやすさを優先 | 写真を置かない |
| Contact | なし | 問い合わせ導線を優先 | 写真を置かない |
| Privacy / Terms / Accessibility | なし | 法務文書の可読性を優先 | 写真を置かない |
| Certificate Verification | なし | 証書番号の確認操作を優先 | 写真を置かない |

## Homeの現在の3枠

### `home-hero`

- 用途: 映画祭名と主要CTAの背景。
- 写真: 青い夕暮れの架空の独立系映画館外観。
- 見せ方: 左の空を文字領域、右の建物を主役として使う。
- 編集値: `display.position`、`display.mobilePosition`。

### `home-screening`

- 用途: 選考説明から受賞項目へ移る場面転換。
- 写真: 上映前の無人の客席。
- 見せ方: 横長全面表示。原画像内の上下の白帯は `display.scale` で枠外へ逃がす。
- 編集値: `display.scale`、`display.mobileScale`。

### `home-in-person`

- 用途: In Person形式の補足。
- 写真: 架空の上質な劇場ロビー。
- 見せ方: 説明文に従属する小さな編集写真として扱い、会場確定の証拠には見せない。
- 編集値: `display.position`、`display.mobilePosition`、`display.scale`。

## 差し替え単位

1. `src/config/image-slots.json` の対象IDを確認する。
2. `file` で公開画像を差し替える。
3. `position` を `50% 50%` 形式で調整する。
4. 必要な場合だけ `scale` を `1.00` 以上へ上げる。
5. PCとスマートフォンで確認する。
6. 権利情報と承認状態を更新する。
