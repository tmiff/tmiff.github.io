# Film Festival Public Site

Astro-based bilingual public site. English is served at `/` and Japanese at `/ja/`.

## Local development

```bash
npm install
npm run dev
```

The repository intentionally starts in preview mode. Replace the values in
`src/config/site.json`, approve all image records in
`src/config/image-slots.json`, and import a readiness attestation generated by
the private operations repository before running `npm run build:release`.

## Source-of-truth boundaries

- Public copy: this repository under `src/content/`.
- Public brand and schedule settings: `src/config/`.
- Submission, inquiry, review, award, and audit data: private operations repository.
- Credentials: Apps Script Properties and GitHub Secrets only.

See `docs/` for editing, image replacement, and custom-domain procedures.
